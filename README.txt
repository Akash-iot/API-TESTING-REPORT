# API Security Risk Analysis 🔐

A hands-on API security assessment project focused on identifying and analyzing common API security vulnerabilities using **Postman**.

This project evaluates publicly available demo APIs (JSONPlaceholder) to identify security risks, understand their potential business impact, and recommend suitable mitigation techniques.

### 🔍 Security Findings
- Unauthenticated Access
- Excessive Data Exposure
- Missing Rate Limiting
- Weak Input Validation
- Broken Authorization (BOLA Risk)

### 🛠️ Tools Used
- Postman
- REST API Testing
- HTTP Methods & Status Codes
- API Security Analysis

### 🎯 Project Objectives
- Analyze API endpoints and responses.
- Identify common API security weaknesses.
- Classify vulnerabilities based on severity.
- Understand potential security and privacy impacts.
- Recommend security improvements and mitigation techniques.

### 📂 Repository Contents
- `report/` – Detailed API Security Assessment Report.
- `screenshots/` – Evidence of API testing and identified security issues.

**Note:** Testing was performed only on publicly available demo APIs for educational purposes. No harmful exploitation was conducted.
